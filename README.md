# Zerodha Website Clone

# About the Project

The Zerodha Website Clone is a frontend web development project inspired by the Zerodha trading platform. The project replicates the clean and user-friendly interface of a modern stock trading website, including sections for trading, investing, products, pricing, and user account access.

The main objective of this project was to improve practical skills in frontend development, responsive web design, component-based development, and UI/UX implementation.

# Technologies Used

- HTML5 – Structure and layout of web pages
- CSS3 – Styling, animations, and responsive design
- JavaScript – Interactive functionality
- React.js – Component-based frontend development
- Bootstrap / CSS Framework – Responsive UI design
- Git & GitHub – Version control and project hosting

# Key Features

- Responsive Zerodha-inspired homepage
- Navigation bar with multiple sections
- Trading and investment-related sections
- Products and pricing pages
- Login/Signup UI
- Clean and modern user interface
- Mobile-friendly responsive design
- Reusable React components

# Learning Outcomes

Through this project, I gained practical experience in React.js, responsive web design, frontend architecture, Git/GitHub, and creating professional-looking web interfaces.
